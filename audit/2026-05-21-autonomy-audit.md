2. **Duplicate density**: 40 of 83 entries (48%) are **C-class duplicates/symptoms**. The `learned-patterns.json` format allows multiple regexes per category, but the current file has many near-identical duplicates (e.g., `review_qa_non_test_dirty_hygiene_failure` appears 6+ times with nearly identical patterns). A deduplication pass would reduce noise.

3. **PR5 scope tension**: 8 B-class patterns target PR5, but PR5's acceptance only adds two static checks (import-vs-usage + file existence). The Round 2 CRITICAL note (still pending) asks for T2/T4/T5 validator checks that are not yet described in implementation tasks. The human operator should decide whether to expand PR5 or narrow the Test Spec.
